# Church Main redesign evaluation

These captures document a design-direction experiment. This branch is not a
production candidate, final design approval, or a request to replace the live
Church Main experience.

The experiment tests how ideas from the House of Praise reference—and lessons
from the Woman Excel redesign exploration—could translate to Cornerstone's own
identity without copying either site.

## What this experiment is testing

- a full-bleed, image-led opening rather than a contained homepage carousel;
- oversized editorial typography and sharper changes in scale;
- a warmer, more expressive navy, coral, blue, lime, and paper palette;
- asymmetric compositions for welcome, event, and ministry content;
- a simplified global navigation and more distinctive footer;
- staged entry motion, scroll reveals, parallax, marquee movement, and playful
  hover treatments; and
- independently composed desktop and mobile layouts.

## What is deliberately not final

- brand direction, typefaces, palette, photography, or homepage copy;
- the generated worship hero, which is a concept placeholder;
- content hierarchy or final calls to action;
- final motion density and interaction behavior;
- the interior-page design system; and
- approval to merge, deploy, or ship any part of this branch.

## Review questions

- Which visual ideas feel recognizably Cornerstone and are worth carrying into
  the real design process?
- Is the editorial scale inviting, or does it overpower the church's message?
- Which motion ideas add warmth and energy, and which feel distracting?
- Does the bolder palette still feel trustworthy and welcoming?
- Does the mobile composition preserve the same confidence as desktop?
